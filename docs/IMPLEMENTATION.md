# 实现与验证记录

## 结构

```text
Vue 表单 / 看板
    -> REST 控制器 + Bean Validation
    -> TaskService（事务 / 状态规则 / 版本检测）
    -> JdbcTemplate 参数化 SQL
    -> H2 tasks / activities
```

核心文件：`TaskController.java` 定义接口与参数约束；`TaskService.java` 负责状态流转和事务；`schema.sql` 定义数据约束与索引；`ApiErrorHandler.java` 统一错误；`LocalSecurityFilter.java` 定义本机演示边界。

任务更新采用数据库条件更新，版本比较不只依赖 Java 内存检查。两个并发事务用同一 version 提交时，只有一个更新行数为 1，另一个返回 409。活动记录与任务更新共用事务；版本冲突不会插入记录。

## 可复现的演示

1. 首次启动空数据库，在页面添加演示任务。
2. 创建一个任务，验证它进入待办列；切换到进行中，再受阻，再进行中，再完成。
3. 搜索负责人或标题关键词，切换优先级筛选，查看结果数量与分页。
4. 打开同一任务的两个页面，在第一个页面编辑并保存，第二个页面用旧版本提交，确认显示冲突提示；刷新后看到第一个页面内容。
5. 打开活动记录，确认创建、编辑和状态变化记录；冲突提交不增加记录。
6. 停止并重启服务，确认任务仍存在。
