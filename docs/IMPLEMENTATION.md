# 实现与验证记录

## 当前结构

```text
Vue 登录 / 项目切换 / 看板 / 成员 / 评论与活动
  -> Spring Security Session + CSRF
  -> REST 控制器 + Bean Validation
  -> ProjectService / TaskService（成员授权、状态规则、事务、版本）
  -> JdbcTemplate 参数化 SQL
  -> H2 users / projects / project_members / tasks / comments / activities
```

`SecurityConfig.java` 从数据库校验 BCrypt 密码，表单登录成功后轮换会话；`LocalSecurityFilter.java` 限定本机 Host、同源写入和已知请求长度，并发送安全响应头。前端不把密码或 Token 写入 localStorage。首次空库启动的虚拟账号密码由环境变量配置。

每个任务接口同时包含项目编号和任务编号。`ProjectService.require` 逐次读取当前成员关系；外部账号看不到项目，viewer 不能写入，成员管理只允许 owner。任务、评论、统计及审计记录均通过这一项目边界访问，旧版全局任务接口已移除。

## 一致性取舍

同一项目的写入事务先锁定项目行，再校验成员角色，防止角色撤销和任务分派交错完成。不同项目可以分别写入；同项目写入短暂串行，适用于本机小规模演示，不据此宣称生产吞吐量。

任务保存使用数据库条件更新：`WHERE project_id = ? AND id = ? AND version = ?`。任务修改和任务 / 项目活动共用事务；旧版本提交返回 409，失败提交不留下成功活动。状态迁移由服务端白名单限制，而非仅靠页面按钮。

编辑者降级 viewer 时，在同一事务内清除其分派、递增相关任务版本、写入任务和项目活动。owner 角色不能经成员接口修改，避免项目失去负责人。评论作者从实际登录身份取得，客户端不能指定 actor；评论本身不改任务内容版本。

## 可复现的协作演示

1. 依据 README 配置虚拟演示密码并启动，owner 登录创建项目，添加 editor / viewer。
2. 创建任务并分派 editor；编辑者推进状态、发表验收评论。
3. viewer 可查看任务、讨论与活动，页面和服务端均禁止写入；guest 看不到未加入项目。
4. owner 将 editor 降级 viewer，确认分派清除、版本变化和审计记录。
5. 两个页面编辑同一任务：先保存一个，再用旧页面提交，确认冲突提示；加载最新内容并确认后才可保存。
6. 关闭并重启应用，重新登录查阅已保存内容。

## 验证边界

这是 AI 辅助开发的个人实践作品，未上线商用，没有真实团队使用、压测或性能提升数据。本机 HTTP Cookie 没有 Secure 标志；公网部署需 HTTPS、生产凭证管理、限流、分布式会话及迁移方案。固定虚拟账号不包含公众注册、邮件邀请或密码找回。H2 不是 MySQL，也未实现 WebSocket、附件或移动端应用。

默认 `mvn verify` 依赖使用者本机 Maven 设置；若本机镜像或缓存不适配，应按官方 Maven 方式修正环境。此次独立复核使用已有工作区依赖缓存和离线设置，不修改用户系统 Maven 配置。
